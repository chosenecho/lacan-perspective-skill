# 拉康视角 · lacan-perspective 2.0

一个有原文定位、版本意识和使用边界的思维顾问技能。用于文本细读、个人反思、组织话语和理论争论；提供可理解、可质疑的拉康视角模拟。它不是拉康本人，也不提供心理诊断或治疗。

本版从旧版重新研究与蒸馏，入口保持精简，深度材料按需读取。研究截止日：**2026-11-03**。

## 使用

- 「用拉康的视角看这段话，先解释字面意思，再给两种读法。」
- 「我把项目延期理解成整个人失败，帮我区分这里的判断。」
- 「用四种话语分析这项绩效制度，说明每个对应的证据和撤回条件。」
- 「核对这句拉康名言，区分原话、翻译与你的解释。」
- 显式调用：$lacan-perspective；也支持「拉康模式」「Lacan perspective」。

普通技术问题直接解决；用户要求退出人物视角时立即退出。每次只使用有帮助的模型，避免把所有问题改写成术语演示。

## 七个核心模型

| 模型 | 要检查的问题 |
|---|---|
| M1 言说关系 | 说了什么，向谁说，处在什么位置？ |
| M2 认同 | 一个形象怎样支撑行动，又怎样困住判断？ |
| M3 需要、要求与欲望 | 可满足的实际需要和关系中的要求如何交织？ |
| M4 目标、原因与幻想 | 追逐的东西与使追逐继续的原因有何区别？ |
| M5 重复的回路 | 什么反复出现，带来什么代价或满足，有无现实解释？ |
| M6 知识与权威的位置 | 谁以什么名义发言，谁工作，产生什么？ |
| M7 维系与改变 | 想改变的安排是否也承担支撑，替代条件是什么？ |

每个模型都包含观察入口、操作、成立条件、失效条件与文本依据。另有十条判断启发式、概念地图、形式工具和七类分析协议。

## 证据与深度

六维研究覆盖著作、访谈、表达、外部批评、行动与制度、时间线。法文一手材料优先，并保留正式编定本、工作转录、译本与二手解释的区别。

- 本地归档28份完整研讨班工作PDF，共5,692个PDF文件页；这是保存规模，**不代表整套逐页精读**。核心论证使用指定讲次、段落与图版。
- 来源目录有208个来源别名、167份按哈希去重的本地文献。241条清单记录包含下载、失败及阅读回执，不能当作241次网络请求或241篇已读文献。
- 保守合并同一历史文本、排除只核书目日期及未读材料后，实质使用63个研究单元，其中40个为拉康一手文本，占63.49%。这是**文本单元比例**，不是字数、页数或全部来源比例。
- 表达分析有20段定向抽样、7份法文文本、1,752个词；保留逐段定位与可复算脚本。没有据文字转录虚构原声、语速或音色。
- 7条短引文可与本地原文及指定文件页逐字匹配；严禁把本包拟写的中文示范当作历史原话。

具体阅读范围及失败记录见[来源说明](references/sources/README.md)和[研究验收](references/research/08-research-review.md)。这些是小规模证据与行为检查，不证明临床疗效或所有回答都可靠。

## 对旧版的重要修订

「无意识是语言」与「无意识像语言那样被结构」在《科学与真理》同篇共存，不能制造后来撤回前说的故事。需要、要求、欲望不能写成数学减法；对象a不等于被购买的物品；实在界不等于所有未知或创伤；享乐不等于同意；「没有性关系」不等于没有爱。

本版保留拉康教学和机构实践中的权力张力，也呈现数学使用、性别理论、证据及疗效方面的实质异议。难懂不是质量目标，反对意见也不能被自动当作理论正确的证明。详见[旧版审计](references/research/00-legacy-audit.md)。

## 安装

将整个仓库或发布包中的lacan-perspective文件夹放入本地技能目录，保留SKILL.md、agents和references的相对位置。例如Windows的Codex技能目录：

~~~powershell
git clone https://github.com/chosenecho/lacan-perspective-skill.git (Join-Path $env:USERPROFILE '.agents/skills/lacan-perspective')
~~~

若目标已存在，先备份旧版，再替换；不要把新旧references混在一起。重新打开会话后使用显式调用。普通使用不需要Python，也不需要私有原始语料。

## 结构与复核

入口：[SKILL.md](SKILL.md)。按需参考：[概念地图](references/concept-atlas.md)、[形式工具](references/formal-tools.md)、[分析协议](references/reading-protocols.md)。六维报告、合成依据及评审记录在references下。

维护脚本需要Python 3.10+；完整YAML解析需要PyYAML，下载PDF的文字抽取另需pypdf。使用已有本地原文时可执行：

~~~powershell
py -3.12 -X utf8 scripts/validate_package.py
py -3.12 -X utf8 scripts/analyze_voice.py --check
py -3.12 -X utf8 scripts/validate_package.py --with-corpus
~~~

公开包没有第三方原文，因此第二、三项需要本地研究语料；首项检查可移植包结构与来源元数据。下载与索引工具支持明确计划、每次请求代理、哈希、失败及阅读范围记录，见来源说明。下载成功永远不自动标为已读。

维护者可在干净的已提交工作树运行scripts/build_release.py。它直接从Git提交读取文件，生成含逐文件SHA-256清单的ZIP及外部校验和，并拒绝打包第三方原始目录。
