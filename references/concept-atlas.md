# 概念地图：先辨别，再使用

这不是临床诊断词典。概念译名随译者而异，首次使用可附法文。以下是跨文本阅读的工作性区分；具体问题仍须回到文本、时期与版本。W/C/E编号可查六维研究；STA-Sn是本地Staferla工作转录。文件页不等于Seuil印刷页。

## 一、主体、言说与认同

| 概念 | 工作性说明与时期线索 | 常见误用／何时停用 | 证据入口 |
|---|---|---|---|
| 主体 sujet | 言说中被代表、又不能与其代表完全重合的主体；不等同自传中的完整个人 | 不能据此取消法律责任、身体与社会处境 | W03；W06；W13 |
| 自我 moi | 与形象、认同和误认相关；晚期也可能有维系作用 | 「自我都是假的，所以应该粉碎」不成立 | W01；S23 1976-05-11 |
| 镜像阶段 | 1949文本讨论对完整形象的认同及其张力；1936报告与1949成文不是同一版本 | 不等于照镜子发现真实自我，不是每个成人行为的单因解释 | W01；W17 |
| 误认 méconnaissance | 认同中的结构性认识方式，并非一句「你看错了」 | 不可把用户的否认自动算作误认的证据 | W01 |
| 理想自我／自我理想 | 可先区分理想化形象与评判该形象的符号位置；精确图式随文本而变 | 不能仅凭中文词序就给人分类 | W06图式与原文；M2 |
| 想象界 Imaginaire | 形象、相似性、认同与竞争的维度，1953已与另两界并列 | 不是幻想作品或所有「不真实」事物的垃圾箱 | W02；W01 |
| 象征界 Symbolique | 能指差异、亲属/法则/言说关系等；不只是明文法律 | 不能把任何组织规章等同整个象征秩序 | W03；W04；W06 |
| 实在界 Réel | 含义演变；晚期与不可能、形式化的障碍有关，不能简化成客观现实 | 未知、资料缺失和现实困难并不自动是实在；创伤不是唯一意义 | S11 1964-02-12；S22；S23 |
| 大他者 Autre | 言说所预设的场所、能指秩序与被诉诸的保证位置 | 不是一个操控一切的人，不把社会想成统一有意图的主体 | W06；W13 |
| 小他者 autre | 常指相似者、镜像性对手等；仍须看具体用法 | 不能以大小写判定人物的道德等级 | W01；W17 |
| 能指 signifiant | 在差异关系与链条中运作，不是装着固定秘密意义的容器 | 法语音义不能无损迁移为中文谐音；也不能宣称一切词都无意义 | W04文件页3–9 |
| 所说／言说 énoncé/énonciation、dit/dire | 分析内容与说出的行为/位置。两组术语有联系，但不能直接当完全同义 | 背后的「真正意思」不是读者可任意填入的隐情 | W03；W06；W16开篇 |
| 无意识 inconscient | 与语言结构、能指和言说有关；S11有comme un langage，W12《科学与真理》同篇同时有est langage与est structuré comme un langage | 不化约成可解码隐藏信息；两种措辞共存，不能未经论证写成后来撤回或阶段替代，也不能说他从未用过前一变体 | S11 1964-01-22；C03问答；W12文本行548–550、608–610（本地抽取定位，非印刷页） |
| lalangue | 晚期关注语言的物质、享乐与个别遭遇；中文可见「语言体」「母语言」等译法，须交代 | 不是标准语言学中的母语同义词，也不是只靠谐音自由联想 | S20 1973-06-26；C13c |

## 二、欲望、身体与重复

| 概念 | 工作性说明 | 常见误用／何时停用 | 证据入口 |
|---|---|---|---|
| 需要 besoin | 可以提出具体满足条件的身体/现实需求层面；进入言说后关系会改变 | 不能用抽象欲望抹掉现实匮乏 | W05文件页25–28 |
| 要求 demande | 说给他者的请求，可能同时要求爱或承认 | 不等于每次明确请求都是操控或爱之索求 | W05；W06 |
| 欲望 désir | 在需要与要求关系中不能被完全满足/表述的维度；与他者有关 | 不是所有冲动、个人爱好、人生使命或固定的真我 | W05；W13 |
| 他者的欲望 | 可涉及欲望的形成、被欲望的要求以及对他者欲望的疑问；具体句法有多义 | 「别人喜欢什么我就喜欢什么」只是其中一种浅化 | W06；W13 |
| 对象a objet petit a | 欲望原因/剩余的功能；乳房、粪便、凝视、声音等列表并非物品身份表 | 手机、钱、伴侣不因被追逐就自动是对象a | S11 1964-05-13；W05 |
| 幻想 fantasme | 可组织主体与对象关系的场景/框架，不止一幅可意识到的幻想画面 | 不是任何错误信念；不能据一段叙述宣布对方根本幻想 | W06；S11 |
| 缺失 manque | 结构论述中的区别，不是对一个人「有缺陷」的评语 | 现实缺钱不能只解释成存在性缺失 | W06；W13 |
| 驱力 pulsion | 与回路和满足有关；与本能、欲望和强迫行为须区分 | 不能据重复直接诊断成瘾或认定想要伤害 | S11 1964-05-13 |
| 重复 répétition | 不能仅理解成同一事件的机械再现；S11区分automaton/tuché的讨论需留语境 | 每次巧合都归入结构使理论失去区别能力 | S11 1964-02-12 |
| 享乐 jouissance | 可超出舒适/快乐原则，并随时期变化 | 不等于开心、同意或施害的正当化；「你其实享受受虐」应拒绝 | S17 1969-11-26；S20 |
| 焦虑 angoisse | S10中的特定理论安排，不只是一般紧张的替代术语 | 普通反思不能据此诊断；本包未把S10下载等同整卷精读 | STA-S10可作后续核验，不作此包核心证据 |
| 凝视／声音 | S11及其他文本中作为对象相关功能讨论，不等于眼睛看或声带发声本身 | 不把被观看感直接诊断为某种结构 | S11；M4 |

## 三、临床、伦理与形式化

| 概念 | 工作性说明 | 常见误用／何时停用 | 证据入口 |
|---|---|---|---|
| 移情 transfert | 与被假定知道等位置有关，不只是喜欢/讨厌分析师 | 代理不能把自己塑造成必需的全知对象 | C06；S11 |
| 被假定知道的主体 | 对知识的假定产生关系效应，不证明某人实际知道全部 | 不应拿这个概念为谎称知道辩护 | C06 |
| 症状 symptôme | 意义、满足与生活组织可交织；不只有要消灭的错误信息 | 不把一切生活困难临床化，也不浪漫化痛苦 | C11文件页5；S23 |
| sinthome | 晚期S23的特殊写法与维系/补缀问题，围绕Joyce而展开 | 与早期症状并非无差别同义；艺术才华不是临床证明 | S23选读；C15 |
| 父之名／父名 | 不同时期与命名、法则、替代及晚期复数化有关 | 不等于现实父亲强势，不据父亲缺席推断精神病 | W06；S22/S23；本包不提供结构诊断程序 |
| 菲勒斯 phallus | 作为能指的理论用途不能简化为阴茎；其理论中心性仍可受批评 | 「不是器官」不能自动驳倒Irigaray等女性主义异议 | W06；E04；E13 |
| 性化 sexuation | S20中位置、量词与享乐的形式化；不直接等于生理男女/性取向 | 不能据身份把人塞入两栏，不能把形式当社会不平等的证明 | S20 1973-03-13；E04/E13 |
| 没有性关系 | 针对可书写的互补关系等问题的论断 | 不等于没有性爱、爱或可持续关系，不作为放弃同意/沟通的理由 | S20；C07c |
| 四种话语 | S17中四个项在位置间的关系形式，不只指说话风格 | 不是四种人格、职业或道德等级 | S17 1969-12-17；形式工具 |
| 数学元／mathème | 形式化与传递的追求；其效果需具体检查 | 不是「已由数学证明临床正确」的证书 | S20；S23；E06/E11 |
| 结与拓扑 | 晚期尝试书写三界维系、补缀与断裂的工具 | 平面图的相似性不能证明心理/脑结构同构 | S22；S23；E06 |
| 不让步于欲望 | S7分析伦理的问题，带有其明确语境与限度 | 不是「想做就做」，不取消承诺、同意、责任或保护 | S7 1960-07-06文件页269、271、275–276 |
| 分析师自行授权／pass | 1967机构与培训争论中的命题及制度安排 | 不是免培训、免督导、免伦理审查的自由执照 | 05行动研究；06时间线 |

## 如何核验一个概念

先写「我现在需要这个概念区分什么」。然后定位到一份具体文本、讲次与说话人；检查词在当段怎样用；再找一个与当前解释不顺的段落。只剩修辞效果、没有可区分后果时，把术语去掉。

局部的概念变化与译名争论应明确保留。「早期/晚期」不能成为忽略反例的万能理由。完整来源、出版/讲授差异及批评见六维研究。
