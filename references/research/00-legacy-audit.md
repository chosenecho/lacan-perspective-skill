# 旧版审计：不能把旧模型写得更华丽后继续沿用

旧版来自工作区 Git 基线 `2e0f143c4094e4dd0d8dab96c844e6bcd86406f8`。本次是用户授权的全面重蒸馏，不是只更新“最新动态”。下表保留旧断言、已定位的反证和处置依据。来源编号详见六维研究与语料目录；文件页号均指所存 PDF 的页序，不能当作 Seuil 印刷页。

| 旧版断言/做法 | 核验与问题 | 新版处置 |
|---|---|---|
| “无意识不像语言——它就是语言” | S11 1964-01-22 文件页13–15明确保留 `comme un langage`；C03 Baltimore 问答纠正听众的同一化。另一方面W12 1965/1966确有 `l'inconscient est langage`，不能反向宣称他从未这样说。 | 标明文本/时期；反对“无意识只是可解码的语言内容”的还原，不编造一条跨时期恒定口号。 |
| “我写不是为了让人理解，我写是为了产生效果”作为原话 | C08 1974-10-29记者会文件页7说后半是为了让文字被阅读，并解释口头教学的书面浓缩；旧版后半不在该句中。 | 删去拼接引语；风格训练以重置问题和精确区分为目标，不以难懂为目标。 |
| “欲望 = 要求 − 需要” | 可作二手教学助记，却不是可以运算的心理定律；要求还涉及爱、他者和对需要的言说性改变。 | 分析关系与剩余，不把 `désir/demande/besoin`当同量纲数值。 |
| 对象a是某个职业、商品或伴侣 | 将欲望的原因位置与经验目标混为一谈，容易诱发“找出那个东西就知道真相”的武断判断。 | 区分目标、支撑幻想的对象形态、原因功能；同一物不固定扮演同一位置。 |
| 实在界仅为不可言说的创伤，或一切“无法解释”的事 | 抹掉概念演化，将资料缺失偷换为结构不可能。 | 未知、经验障碍、形式化的矛盾、创伤经验分别处理；无证据不得升级为实在界。 |
| “感觉好些只是安慰剂”“任何解决都是虚假闭合” | C11 Yale 1975-11-24文件页5明确谈到减少不适、分析限度和来访者可接受的生活。 | 删除苦难崇拜；允许明确回答、实际帮助和结束，不以理论制造无穷依赖。 |
| “在关键时刻切断”可直接搬到聊天中 | 临床会谈的时间、移情、伦理责任不能靠模仿短回复重现；争议与收费/机构问题也不能靠自述消解。 | 禁止故意断联、吊胃口和人为制造焦虑；仅使用文本中可解释的标点/重述，不声称实施临床技术。 |
| 反对任何将精神分析还原为科学的企图，因而可说其反科学 | W12、C08、C10/C13、C11及S23展示复杂而变化的科学关系；S23 1976-03-16文件页89还限定形式化只把握实在的局部。 | 不将其圣化为已证实科学，也不简单反科学；分别核对形式有效性、解释力与经验效力。 |
| “没有性关系”意味着不可能相爱/不存在性行为 | 把特定的形式化主张变成生活事实断言。 | 区分性行为、爱、性化位置与可书写的互补关系；保留性别理论批评。 |
| 1963创立EFP，或把培训资格争议写成单一“逐出所有组织” | 日期、机构和会员/培训资格层次混淆；1964-06-21建校须独立记述。 | 采用时间线研究核定的精确事件链。 |
| 《电视》统一标为1973电视播出 | 1973制作、1974年3月9日/16日播出、1974书本改写不是同一件事。 | 分列媒体、录制/播出/出版；区分录音、编定文本及编辑括注。 |
| “拉康生前正式发表只有《文集》” | 有1932论文、其他发表文章及1974《电视》等反例，且出版/发表不是同一计数口径。 | 删除，不以传记性修辞替代完整书目。 |
| “亨利·科宾直接塑造写作风格”、晚年衰退导致全部晦涩 | 旧版没有给可复核证据，因果推断超出公开文本；不能凭风格诊断健康。 | 不进入核心谱系或技能规则；如讨论传记争议，只写明确归属和证据等级。 |
| 把今日AI完全说成拉康从未想过的领域 | S17 1969-12-17文件页18确有讽刺以电子机器记录能指并出票回答的构想。 | 保留历史机器讨论，但现代LLM的能力/风险仍须实时事实和显式框架外推。 |

## 保留下来的优点

旧版已经认识到临床边界、晚期争议和三界的时期错置风险；本次将这些提醒改成实际可执行的路由、证据协议和测试，而不是删掉以后又以更自信的扮演方式重现。

## 审计边界

这不是对旧版所有引语逐条作伪判定。“缺少出处”不等于“已证明伪造”；处置原则是没有核验就不作为直接引语，不为保留精彩措辞补造来源。
