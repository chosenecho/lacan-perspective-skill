# 本地研究语料与可复查口径

原始资料用于用户授权的私人研究。公开可访问不等于开放许可。仓库的 MIT 许可不覆盖第三方著作、转录、图像和译文；`books/`、`transcripts/`、`articles/` 已加入 `.gitignore`，不默认随仓库发布。

## 文件组织

- `books/staferla/`：研讨班 I–XXVII 加辅助教学《Le savoir du psychanalyste》（S19b），共28份公开工作转录；不是28份均已完整读过的声明。
- `articles/staferla/`：从实际档案目录链接取得的13份论文/教学工作稿；其补注、图重绘、现代参考书目不属于拉康原话。
- `articles/writings/`、`transcripts/conversations/` 等：六维研究所用具体版本与对读资料。
- `manifests/*.jsonl`：各研究维度/批次的获取与抽取记录，保留失败和重试，不清除错误来改善统计。
- `*-plan.json`：明确URL的抓取计划。索引页属于发现工具，不算实质研究文献。
- `catalog.json`：最后整合的本地语料目录。它不把“已下载”“已抽取”“已读”“已验证论点”混为一类。

## 证据等级

1. 本人署名文本及能定位的原始录音/影像。
2. 口头教学转录、本人认可/正式编定的出版文本：属于本人教学的一手载体，但有编辑介入，不能假定彼此字句相同。
3. 译文、公开工作转录、回译：说明原版、译者、改编性质；重大断言尽量与原文或另一版本互校。
4. 同时代证词、作者自述、机构记录：只能证明各自能证明的内容；当事人自述不是对动机/疗效的独立证实。
5. 学术阐释、批评和传记：标明作者及立场，不能冒充拉康的直接表态。
6. 本次框架推断：给出推断桥梁和可推翻条件，不制造历史事实。

批评者自己的文章是“该批评立场的一手材料”，却不因此成为“拉康本人的一手材料”。一手占比的分母和去重方式必须公开。

## 定位规则

抽取文本中的 `[[PDF_PAGE_0086]]` 是**所存PDF第86个文件页**。它不是 Seuil 页码，也不自动等于页脚印刷页。首选“著作/研讨班 + 讲授日期 + 本地版本文件页”定位；遇到网页使用标题/小节/段落开头。未经核验，不编造卷、章、页码。

`scripts/query_corpus.py` 可以查词并返回上下文与文件页。检索命中不等于解释成立；没有命中也不能证明原文没有该句。PDF字体、图形、换行和OCR缺失都可能使检索失败。

## 阅读范围

大型研讨班按问题做关键讲次精读和跨期检索；完整下载只建立可复核底座，不声称通读数千页。每个研究维度在自己的来源表记录实际阅读范围。全文、选段、目录、搜索命中、无法提取、无法取得必须分开。

## 网络与可复现

下载器默认保留TLS校验，仅访问计划中给出的公开HTTP(S)地址，不使用凭据、不绕付费墙或验证码、不修改系统代理。可按运行时需要传入 `--proxy`。Staferla的实际公开链接使用HTTP；其传输真实性弱于HTTPS，因此保留哈希并用其他版本交叉核验核心引文。

运行需要 Python 3.10+；PDF抽取还需要 `pypdf`。示例：

```powershell
python -X utf8 scripts/fetch_sources.py references/sources/staferla-seminars-plan.json --manifest references/sources/manifests/my-refresh.jsonl --proxy http://127.0.0.1:10808
python -X utf8 scripts/query_corpus.py "jouissance" --source STA-S17 --limit 5
```

如果访问被拒或源已下线，保留记录并转用合法公开版本；不把失败页面存成正文，不把扫描封面当作全文。
